Aug 2026

Digital Recipe Cards

A full-stack CRUD web app in Flask for creating, editing, and organizing recipes as printable cards — the index-card recipe box, made searchable.

  • Designed a normalized relational SQLite schema across four tables. Ingredient names live in their own table behind a join, so "olive oil" is stored once no matter how many recipes use it.
  • Implemented the full CRUD surface with server-side routing, form handling, and validation that reports what is missing without clearing the form.
  • Built search that matches a recipe name or any ingredient it uses, resolved through one indexed join. That query is the payoff of the schema.
  • Rendered every card with Jinja templating over SQL query results. Enforced integrity in the database itself: a cascade rule deletes a recipe's children with it, and a restrict rule protects an ingredient still in use.
  • Python
  • Flask
  • SQLite
  • SQL
  • Jinja2
  • HTML

L'Oréal AI-Advisor

A conversational beauty assistant that answers product questions across L'Oréal's makeup, skincare, haircare, and fragrance lines and builds personalized routines.

  • Placed a Cloudflare Worker in front of the OpenAI API. The key stays an encrypted server-side secret, and the browser only calls my own endpoint. The hard part was not the chat interface. It was never sending a credential to the client.
  • Scoped the model to L'Oréal's catalog through system prompting, keeping it on-brand instead of answering as a general assistant.
  • Handled conversation state. A typing indicator appears on send, and the reply replaces it in place. The view scrolls to the newest message.
  • Showed network failures as visible in-chat errors instead of a silent dead end.
  • JavaScript

  • Fetch / async

Nov 2025

L'Oréal Routine Builder

The AI-Advisor made product-aware: browse a 35-item L'Oréal catalog, pick what you own, and get a routine built around those specific products.

  • Built a browsable product catalog from a JSON dataset of 35 products across ten categories. A category filter and a live text search both run against that dataset.
  • Made selection stateful. Clicking a card adds or deletes it, and the selected list updates in place. The selection persists in localStorage, so a refresh does not lose it.
  • Sent the user's selected products to a Cloudflare Worker, which calls the OpenAI API server-side and returns a routine built from those exact items.
  • Kept chat history in localStorage so follow-up questions carry the earlier routine as context instead of starting over.

Intel Sustainability Timeline

A scroll-snapping timeline of Intel's environmental history, 1968–2024, built under one constraint: it had to work completely for someone using a screen reader or navigating by keyboard alone.

  • Semantic structure first — real header, main, section, and article landmarks instead of nested divs, so assistive technology can present a usable document outline.
  • Made every timeline card keyboard-focusable, so the whole timeline is traversable by tabbing rather than only by scrolling.
  • Wrote descriptive alt text conveying what each image contributes, and used visually-hidden labels so form controls announce themselves without cluttering the visual design.
  • Added ARIA region labeling on the timeline and a responsive grid that reflows cleanly to mobile.
